HR Analytics Dashboard – Employee Attrition
📊 Project Overview

An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition and understand workforce patterns.

The dashboard focuses on employee demographics, attrition, job satisfaction, overtime, departments, and job roles.

🎯 Objectives
Analyze employee attrition and retention
Identify attrition patterns across departments and job roles
Analyze the relationship between overtime and attrition
Understand employee job satisfaction
Explore workforce demographics
📌 Key KPIs
Total Employees: 1,470
Employees Left: 237
Attrition Rate: 16.12%
Current Employees: 1,233
Average Age: ~37 years
